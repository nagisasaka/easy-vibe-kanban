<Steps>
<Step title="Deploy the server">
Follow the [server container guide](/self-hosting/server-container) to install the
published Docker image, configure your sign-in credentials and obtain an HTTPS
certificate. Open the server URL and sign in with Basic authentication.

LVK does not publish an npm package. For local source development, use the
instructions in the repository README.

</Step>
<Step title="Authenticate your coding agent">
Authenticate the coding agent inside the container where its sessions will run.
The server image includes Codex CLI; other agents may need installation. Agent
accounts and model usage are separate from LVK's Basic authentication.

The server guide includes the container commands and persistent credential locations.

</Step>
<Step title="Bring in your repository">
Clone or copy your repository under `/repos` in the server container. When creating
a workspace in LVK, select that server-side directory. Configure your Git identity
and repository access before committing or pushing changes.

Choose an isolated worktree for parallel work, or work in place when you need to
edit an existing checkout directly.

</Step>
<Step title="Develop LVK itself">
Enable the optional [source development service](/self-hosting/server-container#develop-lvk-on-the-server).
It gives you a separate HTTPS URL, frontend hot reload and Rust incremental builds.
Use an in-place workspace on the watched checkout to see your changes there.
The stable service can keep managing agent work while the development backend restarts.
</Step>
</Steps>
