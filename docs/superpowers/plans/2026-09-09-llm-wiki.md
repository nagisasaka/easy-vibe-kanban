# LLM Wiki implementation plan

1. Add validated TOML pipeline loading and the bundled `wikillm` definition;
   expose it through a read-only API and generated shared types.
2. Add tested task-description block composition and a task-form pipeline and
   stage selector.
3. Bundle provider-neutral Recall and Enrich skills, materialise them in app
   data, and augment Codex selected skills for valid LLM Wiki prompts on both
   initial and follow-up turns.
4. Add a workspace Wiki service and API for secure snapshots, frontmatter,
   search data, deterministic configuration initialisation and language
   updates.
5. Add the read-only current-workspace Viewer using the existing Markdown and
   Mermaid components, including repository selection, links and search.
6. Add unit and integration coverage for parsing, ordering, idempotency,
   path/symlink safety, language, links, search and session reuse.
7. Update user documentation, format, run focused tests plus full checks and
   lint, review the complete diff, fix confirmed findings and re-run checks.
