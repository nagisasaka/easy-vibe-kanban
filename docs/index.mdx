Lucky Vibe Kanban (LVK) is a self-hosted workspace for coding agents, Git worktrees,
visual workflows and repository memory. It builds on Easy Vibe Kanban and Vibe Kanban.

LVK is distributed as Docker images through GHCR. You can run it on your own server
with HTTPS and Basic authentication using a public IP address; a purchased domain
is not required. Coding-agent accounts and model usage are configured separately.
