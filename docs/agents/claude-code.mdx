---

<Note>
LVK is distributed as Docker images. Use the [server guide](/self-hosting/server-container) for deployment. The `pnpm run dev` examples below require a source checkout with dependencies installed.
</Note>


<Steps>
<Step title="Install Claude Code">
  ```bash
  npm install --global @anthropic-ai/claude-code
  ```

  Vibe Kanban launches the `claude` command from your PATH. Keep the CLI
  updated independently; Vibe Kanban does not bundle or pin a Claude Code
  runtime version.
</Step>

<Step title="Follow the login instructions">
  Complete the authentication flow as prompted. For more details, see the [Claude Code documentation](https://docs.claude.com/en/docs/claude-code/quickstart).
</Step>

<Step title="Start Vibe Kanban">
  Once authenticated, launch Vibe Kanban:

  ```bash
  pnpm run dev
  ```

  You can now select Claude Code when creating task attempts.
</Step>
</Steps>
